# Privacy Policy

This plugin does not collect, store, or log any user data itself.

When a tool runs, the plugin sends these values over HTTPS to the GetYouTubeTranscript API (`https://getyoutubetranscript.com/api/v1`):

- Your GetYouTubeTranscript API key, in the `Authorization` header.
- The tool inputs: the YouTube video URL or ID, language code, timestamps flag, search query, channel, and page or continuation tokens.

No other data is sent, and nothing is sent to any other third party.

How GetYouTubeTranscript handles API requests is described in its privacy policy: https://getyoutubetranscript.com/privacy-policy
